## Setup

1. Install Python 3, then install the requirements:

   ```
   pip install -r requirements.txt
   ```

2. Create a file named `.env` in the project folder with these four keys:

   ```
   ANTHROPIC_API_KEY=
   OPENAI_API_KEY=
   XAI_API_KEY=
   POLYGON_API_KEY=
   ```

3. Run it:

   ```
   python main.py
   ```
